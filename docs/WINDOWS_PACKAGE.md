# Windows package

**Fmpeg Converter v1** Windows ZIP paketi GitHub Releases bölümüne yüklenmelidir.

Paket adı: `Fmpeg_Converter_v1.zip`

Paket, `Fmpeg Converter.exe`, `Fmpeg Converter.ps1`, `README.txt` ve `engine/` klasörünü içerir.

Arşivi tamamen çıkarın; `engine/` klasörünü uygulamanın yanında tutun. FFmpeg GPL dağıtımı için lisans ve ilgili kaynak kod yükümlülükleri kontrol edilmelidir.
